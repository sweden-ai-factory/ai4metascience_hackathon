# AI4Metascience Hackathon

This repository contains Jupyter notebooks, scripts, and supporting materials for the **AI4Metascience NeurIPS Hackathon (10–17 November 2026)**.

## Purpose

The repository provides a shared starting point for participants to explore AI applications in metascience using the LUMI supercomputer.

Each participant receives an individual copy of the repository through the Jupyter for Courses environment on LUMI Open OnDemand (OOD).

## Repository structure

```text
.
├── notebooks/          # Jupyter notebooks and Scripts for running jobs on LUMI
├── docs/               # Setup guides and documentation
├── README.md
```

The repository will be expanded with additional notebooks, scripts, and documentation as the hackathon materials develop.

## Getting started

### 1. Log in to LUMI

Go to the [LUMI Open OnDemand interface](https://www.lumi.csc.fi/public/) and click **Log in to LUMI**.

### 2. Set up your Jupyter environment

To access the AI4Metascience Hackathon course environment, select **Jupyter for Courses**. Detailed instructions on how to configure and launch your Jupyter session are provided in the following guide:

**[Setting Up the Jupyter Environment](docs/setting-jupyter-environment.md)**

Follow the instructions in this guide to configure your session and access the hackathon materials.

## Additional documentation

Guides and examples will be provided for:

- **Python packages:** How to add additional pip packages to the container. **[Create env](notebooks/introduction.ipynb)**
- **SLURM jobs:** How to submit and manage computational jobs on LUMI. **[Slurm script](notebooks/script.sbatch)**
- **API access:** How to use AITTA to generate API tokens and configure API access. **[Aitta API](notebooks/aitta.ipynb)**

Detailed instructions and example scripts will be added to the `docs/` and `scripts/` directories.
